# KiraIsland

Native macOS Dynamic Island experiment built with SwiftUI + AppKit.

## Current milestone

- Stable borderless notch-adjacent panel
- Compact state
- Expanded state
- Click-only toggle
- Animation lock to prevent repeated toggles
- Multi-Space / fullscreen auxiliary support

## Run

```bash
git clone https://github.com/ankaroni/KiraIsland.git
cd KiraIsland
swift run
```
